# 🎓 Student Result Analyzer

A complete and interactive **Student Result Analyzer** built using HTML, CSS, and JavaScript. The application allows users to enter multiple students and their marks, automatically calculates grades, analyzes class performance, and provides options to search, sort, edit, delete, and export results.

## 🌐 Live Website

👉 https://yuktikapoor18-ux.github.io/student-result-analyzer/

## ✨ Features

### 📋 Basic Features

- Add multiple students
- Enter student names and marks
- Automatically calculate grades
- Calculate class average
- Find highest-scoring student
- Find lowest-scoring student
- Count passed students
- Count failed students
- Calculate pass percentage
- Display PASS / FAIL status for each student

### 🚀 Advanced Features

- ✏️ Edit student records
- 🗑️ Delete individual students
- 🧹 Clear all student records
- 🔍 Search students by name
- 🔃 Sort students by:
  - Name A → Z
  - Name Z → A
  - Marks High → Low
  - Marks Low → High
  - Grade
- 📊 Grade distribution
- 🏆 Performance summary
- 📈 Visual statistics
- 💾 Automatically save records using browser local storage
- 📥 Download results as CSV
- 📄 Download results as TXT
- 🖨️ Print results or save them as PDF
- 📱 Responsive design for mobile, tablet, and desktop
- ✅ Input validation
- 🔒 Student data is stored locally in the browser

## 📊 Calculations

The application calculates:

- **Class Average**
- **Highest Score**
- **Lowest Score**
- **Highest-Scoring Student**
- **Lowest-Scoring Student**
- **Number of Students Passed**
- **Number of Students Failed**
- **Pass Percentage**
- **Grade for Each Student**

## 🏅 Grading System

| Marks | Grade |
|------:|:-----:|
| 90–100 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| 40–59 | E |
| Below 40 | F |

**Passing Marks: 40**
